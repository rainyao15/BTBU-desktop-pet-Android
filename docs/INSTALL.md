# 安卓安装教程（一步一步）

> 适用：Android 9（API 28）及以上，实测 Android 15 正常。
> 全程不需要 root，不需要电脑。

---

## 第 0 步 · 拿到 APK

在 [Releases](../../releases) 页面下载最新的 `北工商桌宠-<版本>-btbu.apk`（约 3.4 MB）。

也可以用手机扫码 / 用数据线拷到手机里。放在「下载」目录最省事。

**✅ 成功标志**：手机文件管理器里能看到这个 `.apk` 文件。

---

## 第 1 步 · 允许安装未知来源

不同系统路径略有差异，任选其一：

- **Android 8 以上（推荐）**：点开 APK 时如果弹「出于安全考虑，禁止安装未知应用」，
  点弹窗里的 **设置** → 打开 **允许来自此来源的应用** → 返回 → 再点一次 APK。
- **老系统**：设置 → 安全 → 未知来源 / 安装未知应用 → 允许。

**✅ 成功标志**：安装界面出现「安装」按钮。

---

## 第 2 步 · 安装并打开

点「安装」→ 装完点「打开」。

首次打开会看到设置页：标题「小鲸鱼」，右上角是版本号。

**✅ 成功标志**：能看到「北工商 · 账号与同步」卡片和「🐟 放出来」按钮。

---

## 第 3 步 · 给权限（少一个她都出不来）

1. **悬浮窗权限（必需）**
   设置页点「授权悬浮窗」→ 系统设置里找到「显示在其他应用上层 / 悬浮窗」→ 打开。
   回到 App，「现在的状态 → 悬浮窗权限」应显示 **已开启**。

2. **通知权限（必需）**
   点「授权通知」→ 允许。桌宠靠前台服务常驻，通知栏那条「小鲸鱼在桌面上」就是它活着的意思。

3. **电池优化（强烈建议）**
   Android 12+：设置 → 应用 → 北工商桌宠 → 电池 → 选 **无限制 / 不受限制**
   顺便打开 **自启动 / 允许后台活动**（各厂商叫法不同，见第 7 步）。

**✅ 成功标志**：状态区两个权限都是绿色的「已开启」。

---

## 第 4 步 · 登录并同步

1. 「学号」填你的学号，「密码」填掌上北工商的密码（**只存在手机本地，不上传任何服务器**）
2. 点 **「登录并同步」**
3. 等几秒，状态区会变成类似：

```
第 8 周 · 网费 10.00 · 校园卡 25.80 · 同步于 刚刚
第 9 周 明天 13:40 模拟电子技术实验 @工3-202（实验室）
第 8/25 周（来源：学期开始日）· 开学首周周一=2026-09-07
```

**✅ 成功标志**：余额不再是 `--`，并且出现「第 N 周」。

> 如果提示密码错误：先用手机浏览器登录一次 `掌上北工商`，确认账号能进；改过密码的要重新填。
> 如果余额是 `--` 但周次正常：多半是学校接口临时抽风，等 15 分钟会自动重试，或点一下气泡手动同步。

---

## 第 5 步 · 把她放到桌面上

点 **「🐟 放出来」**。

她会出现在屏幕右下方，点一下会**压扁弹回**并发出一声「拍一拍」；
按住能拖着走；拖到屏幕边缘会自己缩进去躲着。

**✅ 成功标志**：回到桌面还能看见她（说明悬浮窗和前台服务都正常）。

---

## 第 6 步 · 加桌面挂件（可选）

长按桌面空白处 → 「小部件 / 小组件」→ 找到 **北工商桌宠** → 拖到桌面（占 3×2 格）。

挂件上直接显示：时钟、第几周、余额、下一节课、倒计时。

---

## 第 7 步 · 锁屏也能看见（可选）

系统设置 → **无障碍 / 辅助功能** → 已下载的服务 → **北工商桌宠** → 打开。

之后锁屏界面也能看到她（用的是无障碍级的悬浮窗，比普通悬浮窗权限更高）。
不想用了随时关掉，关掉会自动退回普通悬浮窗，其它功能不受影响。

---

## 第 8 步 · 厂商保活设置（重要）

国产系统默认会杀后台，桌宠会「消失一阵又回来」。按机型把下面两项放开：

| 机型 | 要开的地方 |
|---|---|
| **小米 / 红米（MIUI / HyperOS）** | 省电策略 → **无限制**；打开「自启动」；最近任务里给她**加锁** |
| **荣耀 / 华为（MagicOS / EMUI）** | 应用启动管理 → 手动管理 → 允许**自启动 / 关联启动 / 后台活动** |
| **OPPO / 一加（ColorOS）** | 电池 → 允许后台运行；应用 → 自启动 |
| **vivo（OriginOS）** | 电池 → 后台高耗电 → 允许 |
| **三星（One UI）** | 电池 → 后台使用限制 → 从「休眠应用」里移除 |

App 里还有一个 **后台保活** 开关（默认开）：打开后她会从「最近任务」里隐藏，手滑清后台也不会被划掉。

## 常见问题

**Q：点「放出来」没反应 / 一闪就没了。**
A：八成是悬浮窗权限没给。回设置页看「悬浮窗权限」是不是「已开启」；部分机型还要单独给「后台弹出界面」权限。

**Q：通知栏那条能不能去掉？**
A：不能。它是前台服务的凭证，去掉系统就会把桌宠一起杀掉。可以把通知**静音/折叠**，但别关。

**Q：周次和掌上北工商差一周。**
A：设置页有 **「教学周 -1 / +1」**，点一下当场校正，之后按周一自动往下走。
如果换学期了，下次同步会自动清零这个偏移。

**Q：余额一直是 `--`。**
A：先点一下她的气泡手动同步一次；还是不行就重开 App。学校接口偶尔会短暂失败。

**Q：会消耗流量 / 会耗电吗？**
A：只有同步时联网（默认 15 分钟一次，失败自动退避），一次请求几 KB。桌宠是静态立绘，**没有动画帧循环的重绘开销**。

**Q：能装第二只吗？**
A：可以，设置里「桌宠只数」选 1–3 只。

**Q：怎么彻底卸载？**
A：先在通知栏「收起来」或设置页「收起来」，再卸载。不放心的话顺手把无障碍服务关掉。
